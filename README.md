# Reanimatologiya A.İ.T — Supabase Midterm
493 suallıq interaktiv imtahan; düzgün cavablar PDF-də işarələndiyi kimi saxlanıb.

## Quraşdırma
1. Supabase layihəsi yaradın.
2. Supabase SQL Editor-də `supabase/schema.sql` işlədin.
3. Supabase Authentication → Providers → Email aktiv edin.
4. Authentication → URL Configuration → Site URL və Redirect URLs: GitHub Pages sayt ünvanını daxil edin.
5. `config.js` faylında SUPABASE_URL və SUPABASE_ANON_KEY dəyərlərini doldurun. **Service role / secret key brauzerə yazmayın.**
6. GitHub Settings → Pages → Deploy from branch → main/root aktiv edin.

Nəticələr brauzerdə dərhal, daxil olduqdan sonra Supabase-də saxlanır. Səhv sualların tarixçəsi ayrıca təkrar üçün qalır. 440 və 467-ci sualların düzgün cavabı mənbədə göstərilməyib. Eyni hesabla iki cihazda eyni vaxtda işləməyin; son dəyişiklik bütöv vəziyyəti əvəz edə bilər.
